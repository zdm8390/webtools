# はっけよい！超速相撲バトル (Hakkeyoi Sumo Battle)

相撲をテーマにした1回10〜20秒で手軽に遊べるアクションWebミニゲームです。

## 特徴
- **手軽な連打＆タイミングアクション**:
  - **押し出し (連打)**: Spaceキーまたはボタン連打で相手を力押し！
  - **はたき込み (タイミング)**: Jキーで相手の押し込みをかわして形勢逆転！
  - **どすこいバースト (必殺技)**: Kキーでゲージ全消費の猛ラッシュ！
- **ゲームモード**:
  - **横綱昇進モード**: 序ノ口から横綱まで全5階級を勝ち抜く一人旅。
  - **連勝チャレンジ**: エンドレスでどこまで連続勝利できるか挑戦。
  - **2人対戦モード (PVP)**: 1台のキーボード・スマホで友達と熱血バトル。
- **モダンネオン和風演出 & Web Audio音響**:
  - リアルタイム和太鼓・拍子木・ぶつかり・歓声サウンド。
  - 力士のダイナミック物理移動・紙吹雪・カットイン演出。

## 開発スタック
- HTML5 Canvas
- Vanilla CSS3 (モダン和風ガラスモルフィズム UI)
- Pure JavaScript (ES6+, Web Audio API)
