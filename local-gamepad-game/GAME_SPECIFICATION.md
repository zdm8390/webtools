# 🥊 三人称視点 3D街中格闘ゲーム「Urban Breaker 3D」仕様書 (GAME_SPECIFICATION.md)

本ドキュメントでは、ユーザー様よりいただいた仕様に基づくゲーム詳細設計・入力マッピング・ステージ仕様を定義します。

---

## 🎮 1. ゲーム概要 (Game Overview)
- **タイトル (仮)**: Urban Breaker 3D (アーバン・ブレイカー 3D)
- **ジャンル**: 三人称視点 3D 街中破壊アクション格闘 (3D Third-Person Urban Brawler)
- **動作環境**: Windows ローカル環境 (ブラウザ / WebGL 60FPS動作)
- **操作媒体**: コントローラーパッド (標準 Xbox / PlayStation / 汎用 Gamepad) ※キーボード動作もテスト用としてサポート

---

## 🕹️ 2. コントローラーマッピング仕様 (Gamepad Input Mapping)

三人称視点 (3D) での快適な格闘と移動を実現するため、以下のボタンバインドを採用します。

| コントローラー操作 | アクション | 詳細仕様 |
| :--- | :--- | :--- |
| **左アナログスティック / 方向キー (D-Pad)** | **プレイヤー3D移動** | カメラの向いている方向を基準に3Dフィールド上を360度移動。 |
| **右アナログスティック** | **三人称カメラ操作** | プレイヤーを中心に360度回転・上下仰俯角の調整。 |
| **Xボタン / 🟦 (West)** | **パンチ (Punch)** | 近接高速攻撃。連続押下でコンボ。衝撃波エフェクト・ヒット振動。 |
| **Yボタン / 🟩 (North)** | **キック (Kick)** | 威力重視の重攻撃。オブジェクト破壊力大。 |
| **Bボタン / 🔴 (East)** | **ガード (Guard)** | 押しっぱなしで防御姿勢。被ダメージを軽減（または無効化）。 |
| **Aボタン / ✖️ (South)** | **ダッシュ / 回避 (Dash)** | 移動方向に素早くステップ回避。 |
| **LB / RB または LT / RT** | **ロックオン / カメラリセット** | 敵キャラクターを自動注視・カメラ追従。 |
| **Start / Menu ボタン** | **ポーズ (Pause)** | ゲームの一時停止、コントローラー設定・再開。 |

## 🏙️ 3. ステージ & オブジェクト破壊メカニクス (City & Destructible Environment)

### 【ステージ環境】
- **ロケーション**: 夜のネオンが輝く街中のストリート（道路、歩道、ビル群、街灯、ベンチ、木箱、車両等）。
- **ライティング・グラフィック**: リッチなライティング（リアルタイムシャドウ、ネオン輝度、ブルーム効果）。

### 【破壊可能オブジェクト (Destructible Objects)】
1. **破壊対象**:
   - 木箱・ダンボール箱 (Box) : 打撃1発で砕け散る。
   - 街灯・看板 (Street Light) : キックや強攻撃で倒壊・火花エフェクト。
   - 路上ベンチ・ゴミ箱 (Bench / Trash Can) : 吹っ飛んで物理的に破片が飛散。
   - 駐車車両 (Car) : 複数回攻撃すると凹み、最終的に爆発・大破壊。
2. **破壊演出**:
   - 物理パーティクル（破片の飛散、煙・火花）
   - サウンド（木砕音、金属破砕音、ガラス割れ音）
   - **コントローラー振動 (Vibration)**: オブジェクト破壊時に手に力強い衝撃振動を送信。

## 💥 4. 格闘メカニクス (Combat Mechanics)

1. **コンボシステム**:
   - パンチ ➔ パンチ ➔ キック（フィニッシュコンボ）
   - 敵やオブジェクトを大きくノックバックさせる吹き飛ばし判定。
2. **ヒットストップ & 画面揺れ (Screen Shake)**:
   - クリティカルヒット時に数フレームのヒットストップと画面揺れが発生し、爽快感を向上。
3. **ガード & ブレイク**:
   - ガード中はガードゲージを消費。敵の重攻撃やオブジェクト破片が当たるとゲージ減少。

---

## 🏗️ 5. システム構成・実装ロードマップ

- **3D 描画エンジン**: Three.js (WebGL 60FPS)
- **物理・当たり判定**: 3D Raycasting & Bounding Box / Sphere Collision
- **入力管理**: Web Gamepad API ポーリングモジュール (`src/input/gamepad.js`)
- **サウンド & 振動**: Web Audio API & `gamepad.vibrationActuator`
