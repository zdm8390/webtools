# ハッピープライス・パラダイス (Happy Price Paradise) 🛒🎶
～正規表現でそろえる歌詞スロット＆パズルゲーム～

## 概要
ダイソー店内で流れる名曲「Happy Price Paradise」のフレーズ構造に着目した、爽快リズムスロット＆正規表現パズルWebアプリです。

## 主な機能・ゲームモード（予定）
1. **スロットモード（Lyric Slot）**:
   - 「ハッピー」「プライス」「パラダイス」「ダイソー」のリールを止めて、正しい歌詞パターンやお題の正規表現を狙う！
2. **正規表現パズルモード（Regex Challenge）**:
   - 提示された正規表現を満たすように歌詞ブロックを素早く組み立てる！
3. **図鑑・コレクション機能**:
   - 正調歌詞から奇跡の怪文書（珍役）までをコレクション！
4. **Web Audio サウンド**:
   - 店内風の陽気なBGM＆ボイス風ピコピコシンセ演出！

## 技術スタック
- HTML5, CSS3, Modern JavaScript (ES Modules / Canvas / Web Audio API)
- 外部依存なし（単一フォルダで完全動作）
